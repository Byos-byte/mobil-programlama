## 📂 İçindekiler

### 1. ⚛️ React Native Sayaç Uygulaması (`react_native_demo`)
- **AI Düzeyi**: 🤖 Tamamen (AI ile geliştirildi)
- **Açıklama**: Expo ve React Native ile geliştirilmiş modern, koyu temalı sayaç uygulaması.
- **Özellikler**:
  - Sayacı artırma, azaltma ve sıfırlama işlevleri
  - Modern kart tasarımı ve şık buton stilleri
  - Koyu tema ve SafeAreaView desteği
- **Çalıştırma**:
  ```bash
  cd react_native_demo
  npm install
  npx expo start
  ```
